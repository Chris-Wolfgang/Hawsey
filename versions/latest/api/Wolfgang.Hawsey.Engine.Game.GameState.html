A snapshot of the entire game state at a point in time. Each method on GameEngine returns a freshly-constructed instance rather than mutating the previous state, so callers should treat the exposed Hands and CompletedTricks collections as read-only — mutating them is unsupported and can corrupt subsequent engine transitions.

[SuppressMessage("Design", "MA0016:Prefer using collection abstraction instead of implementation", Justification = "Engine returns concrete types; callers must treat collections as read-only per the type's XML doc.")]
