A live game between one human, always South, and three SimpleAiStrategy seats. It is what every Hawsey UI drives: the UI calls the human's moves and the AI-advance methods, and redraws on StateChanged. The AI moves are paced so a person can follow them.

Remarks

Thread safety: the AI loops resume on thread-pool threads after their delays while human moves arrive on the UI thread, so two moves can race for the same turn. So every transition of _state runs under _sync, and each one re-checks, inside the lock, that it is still the right phase and player's turn. A stale human move (a double-tap, a tap during an AI turn) is ignored and reported as false. _generation increments on every new game, so an AI loop that wakes up after New Game stops instead of playing into the new game. Events are raised outside the lock.

AdvanceAsync()

Plays the AI seats' moves, phase after phase, until the game needs something from outside: a move from the human, or the UI's go-ahead for the next round. This is the loop every UI runs after each human move, so they all drive the game the same way. The human's last card of a round is played here too, since there is no choice to make.
